# Cutora

## The open-source alternative to overpriced image tools.

Cutora is an open-source image processing platform built around a simple idea:

**You shouldn't have to pay a subscription just to remove a background from an image.**

Canva has become increasingly aggressive about putting useful features behind Pro subscriptions, usage limits, and paid AI credits. Features that used to be simple standalone tools are increasingly being pulled into a larger paid ecosystem.

Cutora is built to push back against that model.

Instead of forcing users into a massive design platform, Cutora focuses on the tools people actually need.

## What Cutora Does

### Background Removal

Remove image backgrounds automatically and export transparent PNGs.

Designed to handle:

- People
- Products
- Hair
- Fur
- Fine edges
- Objects
- Complex subjects

### AI Image Upscaling

Increase image resolution using AI.

- 2x upscaling
- 4x upscaling
- Detail enhancement
- Before and after comparison
- High-resolution exports

### Image Resizing

Resize images quickly without opening a massive design editor.

- Custom dimensions
- Width and height controls
- Locked aspect ratio
- Percentage scaling
- Preset sizes
- Multiple export formats

## Why Cutora Exists

The internet doesn't need another bloated design platform.

It needs simple tools that do what they're supposed to do.

Canva has turned more and more functionality into reasons to upgrade, while AI features increasingly come with limits, credits, or paid plans.

Cutora takes a different approach.

**Open source.**
**Simple.**
**Fast.**
**Focused.**

No unnecessary design editor.

No subscription just to access basic image tools.

No artificial restrictions designed to push upgrades.

## Performance

Cutora is designed to be fast.

The application prioritizes:

- Fast initial loading
- Lazy loading of heavy AI models
- Efficient image processing
- Web Workers where appropriate
- Minimal unnecessary JavaScript
- Optimized image previews
- Minimal unnecessary dependencies
- Processing only when a tool is actually being used

Heavy AI functionality should not slow down the entire application.

## Open Source

Cutora is fully open source.

Anyone can inspect the code, modify it, contribute improvements, report issues, fork the project, or run their own instance.

The goal is to keep useful image-processing software accessible instead of turning every feature into another subscription.
